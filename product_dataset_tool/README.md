# 商品数据集工具（本地试用版）

Windows 本地工具，用于把手机采集的商品视频转换为可标注、可导出的目标检测数据集。所有文件默认留在本机。

## 普通使用（无需安装 Python）

下载项目输出中的 `商品数据集工具-Windows-试用版-v0.5.zip`，完整解压后，双击 `ProductDatasetTool.exe`。首次打开时选择一个空文件夹新建项目，或选择已有项目文件夹。

## 从源码运行

1. 安装 Python 3.10 或更新版本，并在安装时勾选“Add Python to PATH”。
2. 双击 `启动商品数据工具.bat`。首次启动会安装 OpenCV 和 Pillow；也可以在此目录打开终端运行 `python -m pip install -r requirements.txt`。
3. 选择一个空文件夹创建项目，或选择已有项目文件夹继续工作。
4. 点击“导入录像”，选手机导出的 MP4。若同一目录存在相同文件名的 `.bag`、`.sync.json`、`.frames.csv`，工具也会复制到项目中留档。
5. 点击“批量抽帧”，建议先设为每 1–2 秒抽一帧；删除重复或模糊的帧以后，再添加商品类别/SKU 并在画面上拖框。
6. 点击“导出 YOLO 数据集”。录制段数不少于 3 段时，数据按整段录像拆分为训练、验证和测试，避免相邻视频帧泄漏到不同集合；少于 3 段时暂时全部放在训练集。

## 项目结构

```text
项目文件夹/
├── product_dataset_project.json
├── videos/       # 原始 MP4 和配套 BAG/同步文件
├── frames/       # 抽取的图片
└── exports/      # 可自行选择的导出位置
```

YOLO 导出包含 `images/`、`labels/`、`data.yaml`、`frame_metadata.csv` 和 `split_by_video.json`。每个框使用 YOLO 归一化中心点格式。`frame_metadata.csv` 保留 MP4、时间戳以及配对深度文件的关联路径。

## 当前边界

- 支持视频抽帧、手工矩形框、类别/SKU 标签、项目保存和 YOLO 导出。
- 不会自动识别商品；标签仍由人工确认。
- 首版会复制整段录像，项目文件夹可能很大。请确保磁盘空间足够。
- v0.3 修复了项目路径含中文时抽帧图片写入失败的问题，并兼容中文路径下的 YOLO 图片尺寸读取。
- v0.5 增加通过局域网 Ollama（`192.168.3.8:11434`）调用 `qwen3.6:latest` 对当前画面做视觉预标注，不需要云端 API Key；图片留在你的局域网内。使用时需启动 Ollama 并确认电脑能访问该服务器。AI 框和类别是候选结果，导出前应逐一人工核对。
- 少于 3 段独立录像无法可靠建立训练/验证/测试划分；建议每个划分由不同日期、货架或门店的录制构成。
- 当前尚未读取 BAG 深度帧、批量抽帧需在工具内完成，也未实现多人协作、语音识别、自动模糊筛选和 EXE 安装包。
