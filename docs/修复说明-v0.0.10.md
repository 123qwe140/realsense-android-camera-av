# RS Camera AV 0.0.10 · 相机预览稳定性

针对 0.0.9 中拍摄页偶发黑屏、启动失败的现象：

- 将预览相机启动和等待帧循环移出 Android 主线程，避免阻塞界面响应。
- 进入后台或离开拍摄页时停止相机流；如果启动期间页面已退出，启动完成后立即释放相机流。
- 相机启动失败时在拍摄页显示底层错误信息，便于区分流配置、USB 和设备错误。
- RealSense 原生库保持不变。

此版本尚未在 D435i + iQOO Z7x / Android 13 上验证。需在目标设备上进行反复进出拍摄页、USB 重连及长时间预览测试。

构建验证：Gradle 构建成功，12 项本地 UI/录像库测试通过，APK v2 签名校验通过。安装包为 `outputs/RS-Camera-0.0.10-capture-arm64.apk`，SHA-256：`09f61d7488ae179dfdd9d88b9cf5637b88718301b6f5ace5e9c85b3cb0c9eb14`。
