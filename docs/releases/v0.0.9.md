RS Camera AV 0.0.9 introduces a redesigned Chinese capture experience for RealSense Android.

- Adds a guided connection home screen and clearer camera / USB states.
- Adds a large record control, recording timer, and live phone-microphone level meter.
- Groups MP4, RealSense BAG, and sync files in the recording library; supports playback and export.
- Targets Android ARM64. App ID: `com.intel.realsense.camera.av`.

Install `RS-Camera-0.0.9-capture-arm64.apk` on an Android phone with USB Host / OTG, connect the RealSense camera, and grant USB and microphone access when prompted. This build uses a development signing certificate. A locally built APK uses a different certificate and cannot update this APK in place.

The UI and file handling were verified in local Android tests. RealSense D435i + iQOO Z7x / Android 13 hardware recording, long-run behavior, and audio/video synchronization have not yet been verified on the target phone.

Verify the APK using the attached `SHA256SUMS-v0.0.9.txt`.
