# RS Camera AV 0.0.12 · 相机首帧超时自动重连

用户再次遇到“Frame didn't arrive within 3000”，拍摄页一直停留在“准备相机画面”。

原因已在代码中定位：D435i 的首帧等待超时为 3000 毫秒，超时后启动流程立即失败，预览页没有自动重试。USB 重新协商、相机刚恢复供电或手机负载较高时，设备可能超过 3 秒才输出首帧。

0.0.12 将非 L500 相机的首帧等待延长到 10000 毫秒，并在初次启动或流中断时自动重连，最多尝试 3 次。等待过程留在后台预览线程；用户离开页面时停止操作也不再同步阻塞 UI 线程。

改动文件：

- `source/librealsense-2.58.1/wrappers/android/tools/camera/src/main/java/com/intel/realsense/camera/Streamer.java`
- `source/librealsense-2.58.1/wrappers/android/tools/camera/src/main/java/com/intel/realsense/camera/PreviewActivity.java`
- 应用版本更新为 `0.0.12-capture` / versionCode 12。

验证：Java/资源 APK 构建成功；12 项 Robolectric UI 与录像文件单元测试通过（0 failures / 0 errors）。APK versionCode 12，SHA-256 签名证书与 0.0.11 相同，`librealsense2.so` 与上一版完全一致，可覆盖安装。

目前尚未在 D435i + iQOO Z7x 实机上验证。若三次自动重连后仍无帧，应进一步区分设备供电/USB 链路、设备端流启动和相机 profile 配置；错误提示会保留最终底层异常内容。
