# RS Camera AV 0.0.9 · 拍摄界面改版

日期：2026-10-15。设备目标仍为 D435i + iQOO Z7x / Android 13，手机麦克风，有声 MP4 与原始 BAG 同时保存。

新版安装包：`outputs/RS-Camera-0.0.9-capture-arm64.apk`。

应用包名仍为 `com.intel.realsense.camera.av`，使用本机原有开发证书，可以覆盖更新本机生成的 0.0.8。安装时选择更新，不要卸载原应用。原 0.0.8 APK 保留在 outputs 中；若需降级，Android 通常不会直接允许低版本覆盖，应先导出数据再处理，不能通过卸载来保留应用内录像。

## 改了什么

- **连接首页**：中文指引，显示待授权、等待 USB 授权、未连接、已连接等实际状态；连接后由用户点击进入拍摄。录像库在未连接相机、未授权相机时也可使用。
- **拍摄页**：大面积 RGB 预览、红色录制按钮、独立录像库/设置入口；采集分辨率和帧率显示在顶部。首次收到颜色和深度后检查是否能录制；不满足条件时提示检查设置。
- **录制页**：大号计时、明确的停止方块图标、真实 PCM 音量条、已写入文件大小。返回键会确认是否结束录制；直接按停止则保存。切到后台或锁屏仍沿用停止并保存的规则。
- **保存结果**：底部操作面板提供播放、继续拍摄和打开录像库/导出。
- **录像库**：按日期排列，同一次拍摄的 MP4、BAG 和同步文件归为一项；视频缩略图、时长在后台读取。支持查看深度、回放视频、单文件导出和全部 ZIP 导出。没有完整 MP4 的记录不会被当作可播放的视频。
- **设置**：主要文案中文化，采集配置默认展开，专业设备信息与版本信息折叠；主要设置页可以整体滚动。像素格式 RGB8、YUYV、Z16 等技术名称保留。
- **回放**：统一深色工具栏、返回、导出和分享操作；修复录像库直接进入指定 BAG 的路径传递。
- **外观**：深灰底、薄荷绿状态、珊瑚红录制按钮，统一字号、间距、圆角、触摸区域；使用原生矢量图标和新的应用图标。

固件升级、底层诊断及 SDK 多流/3D 深度查看器仍沿用原有专业工具界面。本轮没有把预览与录制合并为同一个采集会话，因此开始/结束录制时仍可能出现短暂画面切换。

## 安装和快速检查

1. 将新版 APK 复制到手机的 Download（下载）文件夹，在手机“文件管理”中点击更新 **RS Camera AV**。
2. 打开应用，根据首页提示允许相机权限；通过 OTG 线接入 D435i，允许 USB 访问，点击“进入拍摄”。
3. 在设置中保持彩色 COLOR 与深度 DEPTH 开启；首次录制允许麦克风权限。
4. 先录 30 秒并拍手说话，观察计时和音量条，再停止。检查 MP4 声音、画面，以及同组 BAG 是否可回放。
5. 在录像库中打开记录，测试播放、查看深度和导出 ZIP。旋转手机检查横屏控制位置。

音量条来自实际读到的 PCM 峰值，以 -60dB 到 0dB 映射显示；它不是装饰动画，也不是经过校准的声压计。很轻的背景声音也可能使部分条亮起。音量条的变化不能单独证明最终音轨已经成功保存，应以停止后的 MP4 回放为准。

现有录像目录和音视频编码方式不变：

```text
/sdcard/Android/data/com.intel.realsense.camera.av/files/realsense/video/
```

每次记录仍由同名 `.bag`、`.mp4`、`.sync.json`、`.frames.csv` 组成；手机声音位于 MP4，BAG 保留原始相机流。软件同步方式和真机验证限制见原音视频开发说明。

## 开发与验证

主要页面集中在 `tools/camera/src/main/java/com/intel/realsense/camera/CameraUi.java`，由原生 Android View 与 Material 控件组成，按横竖屏组织布局。`DetachedActivity`、`PreviewActivity`、`RecordingActivity`、`RecordingLibraryActivity`、`VideoPlaybackActivity` 负责交互。主要页面不再使用旧的 activity_detached / activity_preview / activity_recording XML 作为入口。

`RecordingItem` 负责文件归组及保存状态，`RecordingExport` 统一处理系统文件选择器导出。缩略图读取和大文件拷贝在后台线程进行。主页面按钮至少 48dp，录制/停止按钮为 80dp。

完整原生构建仍用 scripts/build.ps1；Java/UI 开发用 scripts/build-java.ps1，脚本会生成应用包、真机测试包、执行本地 UI/文件管理测试并输出 `outputs/ui-preview/` 图片。

测试使用 Robolectric 4.14.1 / Android 13 原生图形渲染。截图来自与应用相同的 UI 构建函数；**预览区由黑色占位 View 替代，没有接入真实摄像头**。录像库截图中的文件为测试夹具，不是用户的拍摄记录。这些图片可检查控件、文本、图标和布局，但不能作为 USB、麦克风、编码和音画同步的真机验证。

首次运行测试需下载 Robolectric 的 Android 测试运行时。网络不稳定时，脚本可通过 `-RobolectricSdkDir` 指定已经准备好的运行时目录；本轮使用经 Maven Central SHA256 校验的 Android 13、Android 15 运行时 JAR。本地测试依赖不会放入手机应用 APK。

Java/UI 构建仍复用原 0.0.7 APK 的 RealSense 2.58.1 原生库，没有重新编译 C++。修改 JNI/C++ 时需要完整原生构建。

编译、测试、APK 签名与源码一致性结果记录在 `docs/界面改版验证.txt`。仍未连接用户的 iQOO Z7x + D435i 实测。
