# 超市商品识别数据采集工具方案

## 目标

把 D435i + Android 手机采集到的 RGB 视频、深度 BAG 和录制同步信息，整理成可复核、可标注、可用于商品识别训练的数据集。语音转写用于采集备注和搜索，不代替图像中的商品标签。

## 建议的第一版流程

1. 手机继续负责控制 D435i，录制 RGB 视频、深度 BAG，并保存同名同步 CSV/JSON。
2. 电脑端导入一次或多次录制，批量抽取清晰且有代表性的 RGB 帧，过滤近似重复画面；原始 MP4/BAG 保留并与帧关联。
3. 在电脑端逐张标注商品边界框和类别/SKU，支持快捷键、复制上一帧标注、视频帧相邻跟踪、撤销和复核。
4. 可选读取配对 BAG 深度，为每个商品框计算中心或框内深度统计；深度应作为附加传感器数据，不混进 RGB 图片标签。
5. 记录采集批次、门店/区域/货架、时间、相机配置、商品类目、SKU、包装朝向、遮挡和光照等元数据。
6. 导出原图、YOLO 检测标签、`data.yaml` 和 CSV/JSON 元数据；支持按录制批次划分 train/val/test，避免相邻帧跨集合。

## 首版范围

- 图片/视频导入与抽帧。
- 类别/SKU 清单管理。
- 目标检测边界框标注与标签编辑。
- 录制批次和采集信息管理。
- 语音转文字作为备注，时间戳可跳转回视频。
- YOLO 数据集导出、抽样预览和完整性检查。

## 数据关联

- `session_id`：一段录制及其原始 MP4、BAG、同步 CSV/JSON。
- `frame_id`：抽取帧及其视频时间戳、图像文件。
- `annotation_id`：帧上的商品框、类别/SKU、遮挡等属性。
- `transcript_segment`：语音起止时间、文字、可选说话人；只作备注或检索。
- `depth_summary`：商品框关联的深度统计值及有效像素比例。

## 数据质量规则

- 原始视频只读保存，标注和抽帧可重新生成。
- 每个 SKU 维护唯一编码和名称；未知商品可标为待确认，不猜标签。
- 训练、验证、测试按门店/日期/录制批次分组，不随机拆连续帧。
- 检查模糊、过暗、严重遮挡、空标签和类别不平衡，并保留拒收原因。
- 商品画面及收音可能包含顾客或员工信息；导出公开数据前检查并脱敏。

## 后续评估

首版数据收集稳定后，再根据业务选择检测或分类训练。固定独立测试集，记录每类精确率、召回率、mAP、混淆情况，并用误检/漏检样例指导补采；如果使用深度，还应比较 RGB-only 与 RGB+Depth 的效果。

## 已确定的开发决策

- 操作端：电脑端；手机保留为采集器。
- 标签粒度尚未最终确定，第一版允许类别名直接使用商品大类或具体 SKU。
- 运行模式：纯本地离线优先；若要多人协作，再设计服务端与权限。

## 首版试用工具

`product_dataset_tool/` 已加入 Windows 本地试用版，提供视频导入、按秒抽帧、人工框选类别/SKU、项目保存和 YOLO 数据集导出。打包文件为 `outputs/商品数据集工具-Windows-试用版.zip`，当前 Windows x64 试用包约 96 MB。后续可继续加入 BAG 深度关联、语音备注转写、模糊帧筛选及训练结果回流。
