# RS Camera AV 0.0.11 · 录制预览刷新

用户反馈录制时相机预览长时间停留在旧画面，但录制计时和文件大小继续增长。

此前每收到一帧，程序先同步执行 MP4 视频编码和时间戳/文件写入，之后才通知预览控件显示该帧。若录制处理耗时，预览更新会被延后。0.0.11 调整顺序，先将帧交给独立的 GL 预览队列，再执行录制处理。

改动文件：

- `source/librealsense-2.58.1/wrappers/android/tools/camera/src/main/java/com/intel/realsense/camera/RecordingSession.java`
- 应用版本更新为 `0.0.11-capture` / versionCode 11。

验证：Java/资源 APK 构建成功，12 项本地 UI 与录像库测试通过，APK 签名证书与 0.0.10 相同，可以覆盖安装。SHA-256：`5cf27e5eb441101ab8dfaa93dcbc51805066579e0326c22ecf6a248e1a2f85ef`。

尚未在 D435i + iQOO Z7x 上实测。若安装此版后预览仍冻结，应同时检查导出的 `.frames.csv`：颜色帧编号和设备时间戳持续变化，说明相机仍在送帧，问题更可能在预览渲染；两者停止变化则需检查 USB 帧传输或相机流。MP4 回放也可区分“只是屏幕预览冻结”和“录制视频本身冻结”。
